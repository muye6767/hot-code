```html
<!doctype html>
```

## 2. 星星与流星（stars 画布）
### 2.1 初始化
```javascript
init();                       // 获取 2d 上下文
for(i<800)  new Star().draw() // 随机位置画 800 颗 ❤
for(i<20)   new MeteorRain()  // 20 条流星
playStars();                  // 每 100 ms 随机变色 → 闪烁
playRains();                  // 每 2 ms 移动 + 重绘
```

### 2.2 Star 对象
| 属性     | 说明                         |
| -------- | ---------------------------- |
| `x,y`    | 随机坐标                     |
| `text`   | 固定为 `"❤"`                 |
| `color`  | 50% 几率 `#333` 或 `#ea80b0` |
| `draw()` | `fillText` 绘制              |

### 2.3 MeteorRain 对象
| 属性        | 说明                                        |
| ----------- | ------------------------------------------- |
| `angle=30°` | 控制尾巴倾斜                                |
| `length`    | 150~230 px 随机                             |
| `speed`     | 1~1.5 px/帧                                 |
| `alpha`     | 每帧 `-0.002` 淡出                          |
| `draw()`    | 用 `createLinearGradient` 做粉→白→黑的尾迹  |
| `move()`    | 计算新坐标并 `clearRect` 旧区域实现「擦除」 |

> 流星飞出下边界后自动 `reset()`，实现循环

## 3. 粒子心形（pinkboard 画布）
### 3.1 参数总览
```javascript
settings = {
  particles: {
    length: 500,   // 同时存活粒子数
    duration: 2,   // 单粒子生命周期（秒）
    velocity: 100, // 初速度 px/s
    effect: -0.75, // 加速度系数（负值 = 向内吸引）
    size: 20       // 单粒子贴图大小（px）
  }
}
```

### 3.2 心形数学方程
```javascript
function pointOnHeart(t) {
  return {
    x: 160 * Math.sin(t)³,
    y: 130*cos(t) - 50*cos(2t) - 20*cos(3t) - 10*cos(4t) + 25
  };
}
```
- t ∈ [-π, π]  
- 结果归一化后作为**发射角度**与**初始速度方向**

### 3.3 预渲染心形贴图
离线 canvas 20×20 px，把上述方程路径 `fill()` 成粉色，导出为 `Image` 对象，供所有粒子复用 → 避免每帧实时路径计算

### 3.4 粒子池（ParticlePool）
- 使用 **循环队列** 管理 500 个对象，避免 `new`/`gc`  
- 每帧按 `deltaTime` 更新位置、速度、年龄  
- 年龄到 2 秒即回收  
- 绘制时根据剩余寿命做：
  - 尺寸ease放大再缩小  
  - `globalAlpha` 线性淡出

### 3.5 发射逻辑
```javascript
var amount = particleRate * deltaTime; // 理论每秒 250 个
while(amount--) {
  var pos = pointOnHeart(Math.PI - 2*PI*random()); // 随机角度
  var dir = pos.clone().length(settings.particles.velocity);
  particles.add(canvas.width/2 + pos.x, canvas.height/2 - pos.y, dir.x, -dir.y);
}
```
- 所有粒子从 **同一几何心形边缘** 抛出  
- 加速度为负 → 向中心聚拢，形成「爆炸→收缩」的 3D 观感

## 4. 性能与兼容性细节
1. `requestAnimationFrame` + `Date.getTime()` 计算 `deltaTime` → 保证不同刷新率下速度一致  
2. 使用 `setTimeout(...,2)` 驱动流星，保证尾巴细腻；星星闪烁用 `100 ms` 降低 CPU  
3. 提供 RAF 降级 `polyfill` 兼容旧浏览器  
4. `window.onresize` 双画布同步尺寸  
5. 粒子部分 `clearRect` 全屏清空；流星部分局部清空 → 平衡效率与视觉效果

## 5. 如何魔改
| 目标   | 改动位置                                                |
| ------ | ------------------------------------------------------- |
| 改颜色 | Star.color / Meteor 渐变 stops / 粒子贴图 `fillStyle`   |
| 改数量 | `starCount` / `rainCount` / `settings.particles.length` |
| 改形状 | 重写 `pointOnHeart` 任意参数方程                        |
| 改速度 | `Meteor.speed` 或 `settings.particles.velocity`         |
| 加文字 | 在 `pinkboard` 绘制完毕后 `ctx2.fillText("Love",x,y)`   |
